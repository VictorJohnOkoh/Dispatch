How this Client reaches the Host for the first time

Start the Daemon on the Host with -host-reg, then scan or paste the code it prints. Read the install guide.

The Hub checks the Host's SSH key against the code before it sends the password. It uses the password once to install its own key, and it does not save it.

The Hub borrows this account's SSH agent or the keys in its .ssh directory, and it refuses a Host that this machine's known_hosts does not already name.
